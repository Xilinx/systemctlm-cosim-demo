DCMAC Example Design Highlights
===============================

This directory contains files generated by Vivado's elaboration of the
DCMAC example design:
- Is available as <https://github.com/Xilinx/Vivado-Design-Tutorials/tree/2023.2/Device_Architecture_Tutorials/Versal/NoC_System_Designs/DCMAC_NoC>

- Is what Linux kernel driver supports.

- Can only be used with Vivado 2023.2. If Vivado 2024.1 or newer is used,
  the transceiver block design is missing.

# pl.dtsi
This is one of the many device-tree files generated via the xsct sdtgen
work flow from the example design:

- With the design opened in Vivado, under menu File | Export:
  - Select "Export Hardware..."
  - Choose "Include device image"
  - Click through "Next" to "Finish"
  - Wait for completion of the export

- In a terminal shell,
  - Run xsct to the xsct% prompt
  - sdtgen set_dt_param -dir /PATH/TO/DT_OUTDIR -xsa /PATH/TO/EXPORTED/*.xsa
  - sdtgen generate_sdt
  - exit

- Locate and copy out /PATH/TO/DT_OUTDIR/pl.dtsi

# addrmap-dcmac_0.pdf
This is the default address map generated by Vivado.

The address ranges used by Linux drivers are:

- /M00_AXI_0 : AXI-lite slave register space of DCMAC

- /axi_gpio_gt_ctl/S_AXI : A 32 GPIO output channels connected
  for controlling transceiver tunings.
  The device-tree entry name is _gt-ctrl-gpios_.

- /axi_gpio_tx_datapath/S_AXI : 24 GPIO output channels connected
  to DCMAC gt_tx_datapath[23:0].

  The device-tree entry name is _gt-tx-dpath-gpios_.

- /axi_gpio_rx_datapath/S_AXI : 24 GPIO output channels connected
  to DCMAC gt_rx_datapath[23:0].

  The device-tree entry name is _gt-rx-dpath-gpios_.

- /axi_gpio_reset_done_dyn/S_AXI : 48 GPIO input channels
  - 7..0 connected to gt_tx_reset_done_out[7:0] from
    DCMAC reset controller
  - 39..32 connected to gt_rx_reset_done_out[7:0] from
    DCMAC reset controller
  - Other input channels are not connected

  Thd device-tree entry name is _gt-rx-rst-done-gpios_.

- /axi_resets_dyn/S_AXI : 14 GPIO output channels
  - 0 : tx_core_reset_in
  - 1 : rx_core_reset_in
  - 7..2 : tx_serdes_reset[5:0]
  - 13..8 : rx_serdes_reset[5:0]

  The device-tree entry name is _gt-rsts-gpios_.

The address ranges **not* used by Linux drivers are:

- /APB_M_0 : APB slave register space to access DCMAC's control ports

The address ranges left unconnected in example design:

- /APB_M2_0
- /APB_M3_0
- /M00_AXI_1
- /M00_AXI_2
- /M00_AXI_3
- /M00_AXI_4
- /M00_AXI_5
- /M00_AXI_6
